BLIND ACT

怎么运行
  1. 把压缩包整个解压到一个文件夹（BlindAct.exe 和 BlindAct.pck 要放在一起）。
  2. 双击 BlindAct.exe。

如果 Windows 弹出“Windows 已保护你的电脑”或杀毒软件提示：
  这是因为游戏没有付费的代码签名证书（个人小游戏通常都没有），
  不是病毒。点“更多信息” → “仍要运行”即可。
  如果杀毒软件把文件隔离了，可以在杀毒软件里把这个文件夹加入信任/白名单。

建议戴耳机玩；游戏会用麦克风听你有没有出声（可在设置里关掉）。

------------------------------------------------------------

How to run
  1. Unzip everything into one folder (keep BlindAct.exe and BlindAct.pck together).
  2. Double-click BlindAct.exe.

If Windows says "Windows protected your PC" or an antivirus warns you:
  the game is not signed with a paid code-signing certificate (small
  indie builds rarely are); it is not a virus. Click "More info" ->
  "Run anyway". If your antivirus quarantined it, allow the folder.

Headphones recommended. The game listens to your microphone (you can
turn that off in the settings).
