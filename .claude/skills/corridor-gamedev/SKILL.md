# CORRIDOR — working on this game

First-person horror game, Godot **4.7.2** (Forward+), targeting a single Windows exe.
Almost everything is **built in code** (no hand-edited 3D scenes) and every asset that is
not a reference photo is **generated by a script in `tools/`**, so changes are reproducible
and diffable. Keep it that way: when you need a new asset, add or extend a generator rather
than committing a hand-made binary.

The owner writes in Chinese and reviews on a phone; reply in Chinese, keep screenshots and
the exe flowing. They care about realism, mood, and that the menu matches what they asked
for (they have been precise: centred 开始游戏/设置, no Chinese title, logo "CORRIDOR" with a
blood-spatter "I", icons instead of footer text, an icon next to every option, a language option).

## Toolchain (fresh container)

```bash
bash .claude/skills/corridor-gamedev/scripts/setup_godot.sh      # prints GODOT=...
export GODOT=<printed path>
```
GitHub release downloads, apt and PyPI/npm are reachable; godotengine.org, huggingface and
most asset sites are blocked by the proxy. There is no GPU: rendering uses lavapipe
(software Vulkan) under Xvfb — correct but slow (~1 s/frame at 960x540, more at 720p).

## Map of the project

| Path | Role |
|---|---|
| `scenes/main_menu.tscn` + `scripts/main_menu.gd` | director: endless walk, symptom episodes (`_update_episodes`: heart / dizzy / tinnitus, never the same twice in a row, sometimes with a weaker companion), repeat-vs-random corridor policy (`_seed_for`, loop phases), small random scares, audio mix + muffling, post FX, UI, start-game blackout |
| `scripts/corridor_builder.gd` | materials, shared meshes, banyan + prop templates, backdrop (lake, tree-line cards with world-space UVs, buildings) and the **treadmill**: `update_stream(walker_z)` moves stretches that fell behind to the front and calls `configure(seed)` on them. Constants at the top (BAY=3.2 m, SEG_LEN=6.4 m, N_SEG=14, pillar sizes…) |
| `scripts/corridor_segment.gd` | one 6.4 m stretch: per-key MultiMeshes (fixed max counts, `visible_instance_count`), lamp, tree slot, prop slot. **Everything variable must come from the seed's RNG** so a repeated seed rebuilds an identical stretch |
| `scripts/mesh_util.gd` | box (unit or metre UVs), swept_rect (bench slats), tube (trunks/roots/strands), quad |
| `scripts/flicker_lamp.gd` | pendant bulbs / far floodlight: modes `steady|flicker|dying|dead|end`, `force(level, secs)` for scripted scares, `dropped` signal → heartbeat spike |
| `scripts/fp_walker.gd` | camera: walk, bob, breathing, gaze, `heartbeat_kick()` springs (sub-stepped) |
| `scripts/body_sounds.gd` | heartbeat (separate lub/dub samples so shake hits exactly on the beat) + breathing sets calm/heavy/pant; `stress` 0..1 drives everything |
| `scripts/world_env.gd` | sky, fog, FogVolumes, moon, AgX, `apply_settings()` quality presets |
| `scripts/menu_ui.gd` (+ `horror_button.gd`, `cycle_button.gd`, `ui_widgets.gd`) | logo, buttons, settings rows (icon + label + control), quit prompt, footer icons |
| `scripts/settings.gd` (autoload `Settings`) | persisted options, audio buses (Music/SFX/Ambience/Body), locale |
| `scripts/i18n.gd` | all UI strings as keys → `zh_CN` / `en`; registered with TranslationServer |
| `scripts/dev_capture.gd` | dev-only flags after `--`: `--capture --shots=1.5,4 --out=DIR --z=-20 --noui --nopost --nofog --settings --lang=en --quality=N --exposure=N --trace --dump` |
| `shaders/*.gdshader` | stone atlas (per-face tile via INSTANCE_CUSTOM), wood strips, procedural paving + puddles, water, sky, foliage, strands, building windows, flare (depth-tested starburst), logo, post |
| `tools/` (has `.gdignore`) | generators: `gen_textures.py`, `gen_audio.py`, `gen_logo.py`, `gen_icons.py`, `subset_fonts.py`, `fix_imports.py`, `capture.sh` |
| `art/` (has `.gdignore`) | reference photos and source fonts — never exported |

## Everyday workflows

**After changing any asset or adding files**, re-import (new files are invisible to the
running game until imported, and some import options must be forced):
```bash
$GODOT --headless --path . --import >/dev/null 2>&1; python3 tools/fix_imports.py; $GODOT --headless --path . --import >/dev/null 2>&1
```
`fix_imports.py` sets VRAM compression + mipmaps for 3D textures, BC5 for normal maps,
2x scale + mipmaps for SVG icons, mipmaps for the logo, and `loop=true` for
`bgm_corridor`, `amb_night`, `lamp_buzz`. Add new looping sounds to its `LOOPS` set.

**Check scripts compile / logic runs** (fast, no rendering):
```bash
$GODOT --headless --path . --audio-driver Dummy --fixed-fps 30 --quit-after 600 -- --capture --trace
```
`--trace` prints state, walker z, stress, bpm, breathing set every 5 s and every
`EPISODE` start — use it to verify the symptom scheduler and that the treadmill keeps
recycling (z keeps falling, no errors). `--episode=dizzy|tinnitus|heart` forces one.

**Look at it** (slow; run in the background and do other work meanwhile):
```bash
GODOT=$GODOT tools/capture.sh /tmp/shots "1.5" 1280x720 [--z=-12] [--settings] [--lang=en] [--noui]
```
Then open the PNG with the Read tool. Always look at a frame after visual changes —
several bugs here were only visible on screen (see pitfalls).

**Build the exe** (≈160 MB, pck embedded, icon from `icon.ico`):
```bash
GODOT=$GODOT bash .claude/skills/corridor-gamedev/scripts/build_exe.sh
```
Send `build/windows/Corridor-windows.zip` with SendUserFile; never commit `build/`.
The Linux preset (`build/linux/Corridor.x86_64`) runs here and is a good smoke test of the
exported pack: `build/linux/Corridor.x86_64 --headless --quit-after 30 -- --capture --dump`.

## Adding things

- **UI text**: add a key to `I18n.STRINGS` with `zh_CN` and `en`, use the key as the
  Label/Button text (auto-translated). Then run `python3 tools/subset_fonts.py` — the bundled
  Noto Serif SC only contains characters already used, so new Chinese characters would
  otherwise fall back to a system font. Latin text uses Cinzel (all-caps design).
- **A language**: add `[locale, native name]` to `I18n.LANGUAGES` and a column to every entry.
- **A settings option**: `_slider_row`/`_cycle_row` in `menu_ui.gd` with an icon name; draw
  the icon in `tools/gen_icons.py` (64x64 viewBox, bone `#c9c2ba`, blood `#a3120f`), run it,
  re-import. Persist it in `settings.gd` (`load_settings`/`save_settings`/`apply`).
- **Scares/events**: `main_menu._random_events()`; lamps via
  `lamp.call("force", level, seconds)`; raise `spike` to push the heartbeat. New
  symptoms: add an envelope next to `heart_ep/dizzy/tinnitus`, map it to walker, post
  shader uniforms and audio in `_process`.
- **New things in the corridor**: add a template in `CorridorBuilder._make_props()` (or a
  MultiMesh key in `CorridorSegment.MAX/MATS`) and place it in `CorridorSegment.configure()`
  using only the seeded RNG `r`.
- **New photo-based textures**: extend `tools/gen_textures.py` (perspective-rectify with
  `warp`, de-light with `delight`, then add procedural fine detail — the photos are only
  1280x960, so pure crops look blurry up close).
- **The real game** (after the menu): `PROLOGUE_SCENE` in `main_menu.gd` currently points to a
  placeholder (`scenes/prologue.tscn`); replace it, reuse `CorridorBuilder`, `FPWalker`,
  `BodySounds`, `FlickerLamp`.

## Pitfalls already paid for

- `Control.set_anchors_preset()` keeps the old offsets → zero-size UI stuck in a corner. Use
  `set_anchors_and_offsets_preset()`.
- `Basis.scaled()` scales in the parent frame; for "stretch along my own axis" (strands,
  roots) use `basis * Basis.from_scale(...)`. A radius/scale mix-up once produced 10 m thick
  "roots" that blacked out the whole scene — if the view goes black, suspect giant geometry
  before suspecting the lights (`--testlight`, `--nofog --nopost --exposure=3` help bisect).
- Springs/pendulums must be sub-stepped or clamped: at 1 fps (software rendering) a plain
  Euler spring diverged and set an invalid camera FOV.
- Volumetric fog in a dark scene reads as black murk: keep global density ≈0.005 and get
  halos from per-light `light_volumetric_fog_energy` instead.
- libsndfile's Vorbis encoder segfaults on long files → `gen_audio.py` writes WAV and encodes
  with ffmpeg/libvorbis.
- Piping a Godot export through `head` kills it (SIGPIPE) and leaves `Corridor.tmp`.
- `git ls-tree -l` on a blob-less partial clone downloads every blob — don't.
- GDScript one-line lambdas: keep them to a single statement; call a helper for more.
- Fonts: Godot falls back to system fonts for missing glyphs, which hides missing
  characters in the container (Noto CJK is installed here) but not on the player's PC —
  rerun `subset_fonts.py` after text changes.

## Before you hand over

1. headless `--trace` run shows no `SCRIPT ERROR`;
2. a fresh screenshot of every screen you touched (menu, settings in both languages);
3. exe rebuilt with `build_exe.sh`, zip sent to the user;
4. commit (no `build/`, no `.godot/`) and push to the session branch.
